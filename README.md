## 快速开始

1. 打开[完整目录](docs/CATALOG.md)，找到你要的风格或用途；
2. 点分类标题右侧的「在夸克打开」，进入对应网盘目录；
3. 在夸克网页端登录（免费）后即可在线预览，或存入网盘后用客户端查看——**无需下载到本地**。

> 匿名状态下可以浏览目录和文件名；**在线预览/打开文件需要登录夸克账号**。

## 目录结构示例

```text
S076-100000套ppt模版含莫兰迪高端大气ppt模板/
├── 09莫兰迪/                        # 8 个条目：4 个 pptx + 4 张同名封面
│   ├── 莫兰迪工作总结.pptx
│   └── 莫兰迪工作总结.jpg
├── 8-中国风格/                      # 101 个 pptx + 预览图/
│   ├── 中国风格(01).pptx
│   └── 预览图/
│       └── 中国风格(01).jpg
├── 15-年会颁奖/                     # 115 个 pptx + 预览图/
├── 30-扁平风格/                     # 77 个 ppt + 预览图/
├── 高级感简约古风教学/               # 24 个子风格目录，共 1404 个模板
└── …（共 52 个分类）
```

两种常见组织方式：
- **封面同目录**：`.pptx` 与同名 `.jpg` 并排（如 `09莫兰迪`）；
- **预览图子目录**：模板在分类根目录、封面集中在 `预览图/`（如 `8-中国风格`）。
